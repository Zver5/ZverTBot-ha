## [1.3.0] - 2026-10-06

### Added

- Добавлены кнопки ручного обновления состояния VPS и принудительного переподключения.
- Добавлен расширенный статус соединения с VPS: текущее состояние, последняя успешная проверка, количество последовательных ошибок и время следующей попытки.

- Добавлена информация о способе подключения, хосте, пользователе и порте в диагностические атрибуты.
- Добавлена расширенная диагностика ошибок подключения и более понятные сообщения вместо общего `Unknown error occurred`.
- Добавлено дополнительное логирование неожиданных ошибок Config Flow, Options Flow и операций подключения.

### Fixed

- Исправлена ошибка `Unknown error occurred` при выборе «Создать SSH-подключение» для уже существующего подключения.
- Исправлен вызов некорректного метода SSH-схемы в Options Flow.
- Исправлено переключение существующего подключения на SSH без попытки создать дублирующую Config Entry.
- Улучшена обработка отсутствующего каталога `/config/ssh` при работе с SSH-ключами.
- Исправлено определение возраста данных VPS: `VPS Status Age` теперь рассчитывается по времени `updated_at`, переданному самим VPS.
- Исправлено ручное обновление состояния VPS: кнопка Refresh использует принудительное обновление координатора, а Reconnect сбрасывает задержку повторных подключений.

## [1.2.3] - 2026-09-18

### Changed

- Уточнены названия способов подключения: «Использовать существующий туннель» и «Создать SSH-подключение».
- Улучшены описания обоих способов подключения в мастере настройки и настройках интеграции.
- Уточнено описание SSH-подключения: IP-адрес VPS, SSH-порт и пользователь указываются на текущем шаге, а выбор или создание SSH-ключа выполняется на следующем шаге.
- Обновлены русская и английская локализации.

## [1.2.2] - 2026-09-16

### Added

- Добавлена диагностика состояния соединения с VPS.
- Добавлены состояния соединения `connected`, `failed`, `paused` и `unknown`.
- Добавлены сведения о времени последнего успешного подключения, количестве последовательных ошибок и следующей попытке.
- Добавлена диагностическая информация Home Assistant для анализа проблем подключения.
- Добавлен binary sensor состояния подключения.
- Добавлена реальная проверка SSH-соединения при настройке интеграции.
- Добавлена обработка ручной проверки подключения без изменения состояния основного координатора.

### Changed

- SSH-подключения защищены задержкой повторных попыток после ошибки, чтобы не создавать частые подключения к VPS.
- Canonical endpoint статистики используется через `/vps-status.json`.
- Исправлена совместимость `CONFIG_SCHEMA` с актуальным API Home Assistant 2026.9.x.
- Улучшена обработка ошибок SSH и HTTP при получении статистики.
- Обновлена документация по диагностике и способам подключения.

### Fixed

- Исправлена ошибка загрузки интеграции в Home Assistant 2026.9.x, возникавшая из-за передачи функции вместо результата `config_entry_only_config_schema()`.
- Исправлена обработка ошибок соединения при проверке SSH.

## [1.2.0] - 2026-09-16

### Added

- Добавлена встроенная Lovelace-панель ZverTBot VPS.
- JavaScript панели автоматически подключается через Home Assistant frontend.

## [1.1.0] - 2026-09-14

### Added

- Добавлена поддержка Home Assistant Diagnostics.
- Диагностические данные автоматически очищаются от чувствительных значений.
- Добавлены тесты очистки чувствительных данных в diagnostics.
- Добавлен `@Zver5` в `codeowners`.

### Changed

- Удалено динамическое создание отдельных sensor entities для каждого AWG/Xray-клиента.
- Подробные данные клиентов теперь предоставляются через агрегированные AWG/Xray-сущности.
- Обновление списка клиентов больше не приводит к накоплению устаревших entities.
- Добавлено удаление старых клиентских entities из Entity Registry при настройке записи интеграции.
- Binary sensors сервисов получили device class `running`.
- Генерация нового SSH-ключа корректно создаёт отсутствующий каталог `/config/ssh`.
- Ошибки создания SSH-ключа логируются без раскрытия подробностей в UI.
- Усилен тест генерации SSH-ключа для вложенного пути.

### Fixed

- Исправлена обработка отсутствующего каталога для автоматически создаваемых SSH-ключей.
- Снижена вероятность накопления устаревших клиентских entities после изменения состава VPN-клиентов.

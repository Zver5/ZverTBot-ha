# Changelog

Все заметные изменения проекта документируются в этом файле.

## [1.2.0] - 2026-09-16

### Added

- Добавлена встроенная Lovelace-панель ZverTBot VPS.
- JavaScript панели автоматически подключается через Home Assistant frontend.
- Для использования `custom:zvertbot-vps-panel-v3` больше не требуется вручную добавлять Lovelace Resource.

### Changed

- Регистрация custom element панели стала безопасной при повторной загрузке JavaScript.

## [1.1.0] - 2026-09-14

### Added

- Добавлена поддержка Home Assistant Diagnostics.
- Диагностические данные автоматически очищаются от чувствительных значений.
- Добавлены тесты очистки чувствительных данных в diagnostics.
- Добавлен `@Zver5` в `codeowners`.

### Changed

- Удалено динамическое создание отдельных sensor entities для каждого AWG/Xray-клиента.
- Подробные данные клиентов теперь предоставляются через агрегированные AWG/Xray-сущности.
- Обновление списка клиентов больше не приводит к накоплению устаревших entities.
- Добавлено удаление старых клиентских entities из Entity Registry при настройке записи интеграции.
- Binary sensors сервисов получили device class `running`.
- Генерация нового SSH-ключа корректно создаёт отсутствующий каталог `/config/ssh`.
- Ошибки создания SSH-ключа логируются без раскрытия подробностей в UI.
- Усилен тест генерации SSH-ключа для вложенного пути.

### Fixed

- Исправлена обработка отсутствующего каталога для автоматически создаваемых SSH-ключей.
- Снижена вероятность накопления устаревших клиентских entities после изменения состава VPN-клиентов.

## [1.0.0] - 2026-09-13

- Первый опубликованный релиз ZverTBot VPS для Home Assistant.
